# 정지원 — AI Landing Page Archive

주소: https://pearljng.github.io/

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `projects.js` | **프로젝트 목록 파일.** 이름·업종·소개글·컬러·폰트 등 내용은 모두 여기서 수정해요 |
| `thumbs/` | 메인 카드에 보이는 썸네일 이미지 (1440×900 권장) |
| `index.html` | 메인(목록) 화면 |
| `work.html` | 프로젝트 상세 화면 |
| `style.css`, `app.js` | 디자인과 동작. 평소에는 건드릴 필요 없어요 |

## 자주 하는 작업

### 1. 기존 랜딩페이지 내용 고치기
해당 프로젝트 저장소(예: `vault`)에서 파일을 수정하거나 새 파일을 올리면 끝이에요.
1~2분 뒤 포트폴리오 미리보기에도 자동으로 반영돼요.

### 2. 새 프로젝트 추가하기
1. 새 저장소를 만들어서 랜딩페이지 폴더 안의 파일을 올리고 GitHub Pages를 켜요.
2. 첫 화면을 캡처해서 `thumbs/새이름.jpg`로 이 저장소에 올려요.
3. `projects.js`에서 `{ … }` 덩어리를 하나 복사해서 맨 아래에 붙이고 내용을 바꿔요.
   - 앞 덩어리 끝에 쉼표(,)가 있는지 꼭 확인하세요.
   - 번호는 목록 순서대로 자동으로 매겨져요.

### 3. 순서 바꾸기 / 빼기
`projects.js`에서 덩어리의 위치를 옮기거나 지우면 번호가 자동으로 다시 매겨져요.

### 4. 사용한 AI 툴 표시하기
각 덩어리의 `tools: []` 안에 적으면 상세 페이지에 나타나요. 예: `tools: ["Claude", "Figma"]`
